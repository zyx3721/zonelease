## 📋 版本概述

本版本新增企业微信扫码认证，支持「直连企业微信」与「统一认证中心（wecom-auth-center）」两种接入模式，并提供完整的企微账号绑定 / 解绑体系；界面与交互全面对照 itdb-new 项目优化。文档体系同步重整：根 README 精简为面向使用者的主文档并新增英文版，原根 README 迁移为 `docs/manual.md` 完整手册，部署文档补充 Release 二进制部署流程。

---

## ✨ 新增特性

- 企业微信扫码登录，支持「直连企业微信」与「统一认证中心」两种接入模式，登录页「登录方式」下拉选择企微后进入扫码卡片视图
- 企业微信账号绑定 / 解绑体系：新增 `user_wecom_bindings` 表，用户菜单「绑定企微 / 解绑企微」弹窗扫码完成关联，一个企微账号仅可绑定一个用户，只有已绑定平台用户的企微账号才能扫码登录
- 新增认证配置项：接入方式卡片式切换（直连 / 统一认证中心）、应用配置分组、字段悬浮提示、配置步骤指引、认证中心回调前缀
- 「系统配置 / 基础配置 / 安全时效」新增企业微信扫码有效期，范围 1-60 分钟，默认 5 分钟
- 认证配置保存支持 `clearConfig` 清空语义：清空配置在保存时执行，保存后停用并整体置空；切换接入模式保留另一模式全部配置
- 全局自定义文本选中色（`::selection`），深浅色主题分别适配
- 新增后端与前端服务启停脚本
- Docker 镜像支持 ARM64 架构并推送阿里云仓库；npm 与 Go 依赖源支持构建参数配置

## 🔧 重构优化

- 登录页企业微信交互对照 itdb-new 重构：登录方式下拉统一入口、扫码卡片、主按钮文案切换、独立回调处理视图、授权 4 秒超时恢复、bfcache 页面回退处理、回调参数一次性读取清除
- 系统配置认证面板对照 itdb-new 重构：认证方式卡片式切换、「认证方式 / 应用配置」分组、显示名称只读、移除企微测试按钮与后端测试接口、移除授权方式与获取成员姓名配置
- 用户菜单顺序对齐 itdb-new：修改密码 → 绑定企微 / 解绑企微 → 退出系统
- 企业微信配置清理下线字段（`loginMode` / `fetchName`），统一为 PC 扫码授权入口
- 系统设置面板支持字段悬浮提示（`labelHint`），密码可见按钮空值可点击

## 🔄 API 变更

- 新增 `GET /api/auth/wecom/authorize`：发起企业微信登录，302 跳转企微授权页或认证中心登录页
- 新增 `GET /api/auth/wecom/callback`：企业微信登录回调，校验防伪 state 或调用认证中心 verify 换取身份
- 新增 `POST /api/auth/wecom/exchange`：一次性登录票据换取正式会话
- 新增 `POST /api/auth/wecom/login`：统一认证中心 ticket 直接登录
- 新增 `GET /api/auth/wecom/bind-url`、`POST /api/auth/wecom/bind`、`POST /api/auth/wecom/unbind`：企微账号绑定 / 解绑
- `PUT /api/settings/auth-providers/{id}` 请求体新增 `clearConfig` 字段；企业微信配置保留双模式字段，`mode` 仅决定当前启用的一组
- 移除企业微信认证配置测试接口（`POST /api/settings/auth-providers/wecom/test`）
- 登录、当前用户等用户信息响应新增 `wecomBound` 绑定状态字段

## 📊 数据库变更

## 🔄 升级说明

- 后端启动时会自动执行 `002_user_wecom_bindings.sql` 迁移，无需手工执行 SQL
- 若已部署统一认证中心，建议将认证中心侧本系统的 `callback_path` 配置为 `/login`（前端登录页），以同时支持扫码登录与账号绑定；保留旧配置 `/api/auth/wecom/callback` 时仅支持登录
- 历史配置中如残留 `loginMode` / `fetchName` 字段，下一次保存认证配置时会自动清理
- 升级后企业微信登录行为变更为「仅绑定可登录」：已存在同名平台用户的企微账号需先由用户登录平台完成「绑定企微」后方可扫码登录
