# zonelease v1.2.0 版本更新日志

---

## 📋 版本概述

本版本对企微扫码直连模式进行重构:改用企微官方 JS-SDK 登录面板,授权码经 JS 回调返回、面板不发生页面导航,彻底消除直连扫码后的第一次页面跳变;直连与统一认证中心两种模式的过渡视图与面板尺寸完全一致。同时优化未绑定账号的提示文案、修复整页回跳直连模式的会话换取、补充找回密码邮件字段等问题。

---

## ✨ 新增特性

- **企微扫码直连改用官方登录面板**：引入 `@wecom/jssdk`（动态 import 按需加载），直连模式渲染 `createWWLoginPanel` 官方登录面板（`redirect_type=callback`），扫码确认后授权码经回调返回并与签发 state 一并提交登录接口，面板不发生任何页面导航
- **未绑定账号提示文案优化**：「该企业微信账号尚未绑定系统用户」场景的提示更清晰
- **会话过期跳转登录页补充过期提示**：会话失效跳回登录页时明确提示重新登录，并消除重复跳转

---

## 🐛 Bug 修复

- **整页回跳直连模式会话换取**：企微扫码整页回跳直连模式改用 code 换取会话，修正回跳后的登录链路
- **忘记密码验证码输入框聚焦时误弹冷却提示**：聚焦输入框不再触发冷却期提示
- **找回密码邮件补齐账号与请求来源字段**：邮件内容可定位发起请求的账号与来源
- **会话过期提示重复弹出**：仅在真实会话失效时弹出一次，并清理重复消费块

---

## 🚀 性能优化

- 企微官方 JS-SDK 改为动态 import，仅直连模式按需加载，登录页首屏不承担 SDK 体积

---

## 🔧 重构优化

- **直连面板尺寸与统一认证中心内嵌视图对齐**：面板宽度整卡、高度 380px，两种认证模式切换时登录卡片高度保持稳定；压缩面板内部留白使卡片高度接近本地账号模式
