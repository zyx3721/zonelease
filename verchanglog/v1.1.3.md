## 📋 版本概述

本版本聚焦登录安全与跨项目配置口径统一：新增登录失败锁定机制（连续密码错误达到阈值后锁定，内置管理员 admin 不受限），锁定次数与锁定时长纳入平台「安全时效」配置；找回密码重置成功后自动解除登录失败锁定；前端登录态切换为 localStorage 持久存储，实现同一浏览器内新建标签页与重启浏览器自动登录；SSR 品牌直出的后端地址环境变量与兄弟项目统一为 `SSR_API_ORIGIN`；同时修正 README 中关于 `JWT_SECRET` 与会话失效关系的错误表述。

---

## ✨ 新增特性

- **登录失败锁定**：同一账号连续密码失败达到「安全时效」配置的锁定次数后返回 429 并提示剩余等待分钟数，锁定时长内即使密码正确也会被拒绝，登录成功或锁定窗口过期后重新计数，内置管理员 admin 不受限；仅凭据错误计数，企业微信扫码与一次性票据登录不涉及
- **锁定参数平台化配置**：「系统设置 → 基础配置 → 安全时效」新增「登录失败锁定次数」（3-10 次）与「登录锁定等待时长」（1-10 分钟）两个配置项，后端判定实时读取平台配置，保存时范围校验
- **找回密码联动**：找回密码重置成功后自动解除该账号登录失败锁定（该账号此前的会话吊销能力保持不变）
- **审计增强**：登录锁定拒绝与找回密码重置均写入审计日志
- **浏览器持久登录**：前端登录态由 sessionStorage 切换为 localStorage，同一浏览器新建标签页、重启浏览器均可自动登录；无痕模式与其他浏览器不共享登录态，登录态仅在服务端会话过期（默认 12 小时，401）后失效

## 🔄 API 变更

- `POST /api/auth/login`：新增 429 锁定响应（达到锁定次数时返回剩余等待分钟数提示）
- `POST /api/auth/password-reset/confirm`：行为增强，重置成功后解除该账号登录失败锁定

## 📊 数据库变更

新增迁移 `004_login_failure_log.sql`：创建 `login_failure_log` 表（`username` + `failed_at`）与用户名索引，用于登录失败锁定计数；不改其他表结构，无数据迁移。

## 🔄 升级说明

- 直接替换二进制或更新镜像即可，迁移随启动自动执行，无需手工执行 SQL
- 行为变化提示：登录失败锁定默认开启（5 次锁 2 分钟），可在「安全时效」中调整；浏览器关闭不再清除登录态（localStorage 持久存储），需要退出请使用页面登出；找回密码重置成功后该账号所有已登录设备将被踢下线并解除锁定
- SSR 品牌直出如此前配置过 `ZONELEASE_SSR_API_ORIGIN` 环境变量，请改为 `SSR_API_ORIGIN`；未配置过则无需任何操作
